# 🤖 دليل تشغيل بوت التحميل

## الخطوة 1 — الحصول على توكن البوت
```
1. افتح تيليجرام وابحث عن @BotFather
2. أرسل: /newbot
3. اختر اسماً للبوت (مثال: MyDownloaderBot)
4. اختر username ينتهي بـ _bot
5. BotFather سيعطيك توكن مثل:
   110201543:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
6. انسخه
```

## الخطوة 2 — تثبيت Python
```
حمّل Python من: python.org
تأكد من تفعيل "Add to PATH" عند التثبيت
```

## الخطوة 3 — تثبيت المكتبات
```
افتح CMD أو Terminal في مجلد البوت واكتب:
pip install -r requirements.txt
```

## الخطوة 4 — إعداد التوكن
```
افتح ملف bot.py
غيّر هذا السطر:
BOT_TOKEN = "ضع_توكن_البوت_هنا"

إلى توكنك الحقيقي مثل:
BOT_TOKEN = "110201543:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw"
```

## الخطوة 5 — تشغيل البوت
```
python bot.py
```
يجب أن ترى: 🤖 البوت يعمل...

### انستجرام وتويتر (الحسابات الخاصة)
لو تبي تحمّل من حساب خاص أو ستوري:

3. صدّر الـ cookies وسمّ الملف: cookies.txt
4. ضعه في نفس مجلد bot.py
